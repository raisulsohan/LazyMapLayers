# Sample files for the manual

Small files that tools/manual/chapters use to show importing and numbers. The numbers are **sample
values made up for the tutorial**, rounded and shaped like real data; they are not statistics.
Only `currency.csv` lists real facts (which currency some countries use).

| File | Used in |
|---|---|
| `trans-siberian.gpx`, `trans-siberian-stops.csv` | Chapter 16: a track with times through the railway's main stops, and the stops as places |
| `baikal-area.geojson` | Chapter 16: an area to highlight |
| `coffee-sample.csv` | Chapters 28-31: countries and a number |
| `currency.csv` | Chapter 28: countries and a category |
| `internet-sample.csv` | Chapter 33: internet users per 10,000 people, per country per year. Kept above 90 so it also opens as numbers in 1.0.1, where small numbers were read as coordinates |
| `flights-sample.csv` | Chapter 32: flows between cities |
